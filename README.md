# 달무티

컴퓨터 3~7명과 하는 달무티 카드 게임. 브라우저 하나로 돌아가고 설치·서버가 필요 없어요.

**플레이:** https://2juwon.github.io/dalmuti/

규칙은 나무위키 「달무티」 문서를 따랐습니다.

## 규칙 요약

- 카드 80장: 1(달무티) 1장, 2(대주교) 2장 … 12(농노) 12장, 어릿광대 2장. 숫자가 작을수록 높은 카드.
- 선은 같은 숫자를 원하는 만큼 내고, 다음 사람부터는 **같은 장수 · 더 작은 숫자**만 냄. 패스해도 다음 차례에 다시 낼 수 있음.
- 모두 패스해 마지막에 낸 사람에게 돌아오면 판을 치우고 그 사람이 선. 그 사람이 이미 다 털었으면 다음 사람이 선.
- 어릿광대: 혼자면 13, 숫자 카드와 함께 내면 그 숫자.
- 먼저 다 턴 순서대로 달무티 · 총리대신 · 상인 · 소작농 · 농노. 계급 순서로 앉고 달무티가 선.
- 세금: 농노는 가장 작은 숫자 2장을 달무티에게, 소작농은 1장을 총리대신에게. 받은 사람은 아무 카드나 같은 장수만큼 돌려줌. 어릿광대는 바치지 않음.
- 80장이 나눠떨어지지 않으면 낮은 계급부터 한 장씩 더.
- 혁명: 어릿광대 2장을 받은 사람이 세금 전에 공개 → 농노면 대혁명(계급 뒤집기 + 세금 없음), 다른 계급이면 세금만 없음.
- 첫 판은 카드를 한 장씩 뽑아 계급을 정함(같은 수면 그 사람끼리 다시 뽑기). 설정에서 첫 판만 세금 없이 '평등하게' 고를 수 있음.

## 문서에 없어서 정한 부분

- 점수: 판마다 꼴찌 0점부터 한 계급 위로 1점씩. 3·5·10판(또는 끝없이) 합계로 최종 순위, 같으면 마지막 판 순위.
- 컴퓨터는 소작농·농노일 때만 혁명을 공개함.
- 상인끼리 카드를 바꾸는 선택 규칙은 넣지 않음.

## 컴퓨터

- 느긋한: 절반쯤 아무 수나 둠
- 보통: 약한 묶음부터 털고, 묶음을 쪼개거나 1·2·어릿광대를 아끼는 규칙
- 고수: 남의 패를 아직 안 나온 카드로 여러 번 상상해 끝까지 두어 보고(한 수에 약 800판) 등수가 가장 좋은 수를 고름

컴퓨터는 자기 손패와 공개된 정보(낸 카드, 남은 장수)만 씁니다. 5명 게임에서 나머지가 '보통'일 때 평균 등수(무작위면 3.00): 느긋한 3.65 · 보통 3.00 · 고수 2.68.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | GitHub Pages용 완성본 (`node build.js`로 만듦) |
| `src/engine.js` | 규칙 엔진 `DM` — JSON 상태 + `apply(state, action)` |
| `src/ai.js` | 컴퓨터 `DMAI` |
| `src/ui.html` | 화면 (엔진·컴퓨터가 빌드 때 들어감) |
| `build.js` | `index.html`, `dist/dalmuti.html`(Claude 아티팩트용) 생성 |
| `test/rules.test.js` | 규칙 시험 |
| `test/sim.js` | 컴퓨터끼리 대국 (멈춤·카드 수 검사, 실력 비교) |
| `test/browser.py` | Playwright로 화면을 눌러 한 경기 끝까지 |

## 고치는 법

```sh
node test/rules.test.js      # 규칙 시험
BUDGET=40 node test/sim.js 150   # 컴퓨터끼리 대국
node build.js                # index.html 다시 만들기
python3 test/browser.py "$PWD/index.html" /tmp 390 5   # 휴대폰 폭, 5명
```

저장은 각자 브라우저에만 됩니다(localStorage `dalmuti-v1` — 설정과 진행 중인 경기).
